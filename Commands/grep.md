# Print lines that match patterns
# Cú pháp
```
grep [OPTION] PATTERN [FILE]
```

# OPTION
-e [PATTERN] : Sử dụng $PATTERN làm mẫu. Nếu tùy chọn này được sử dụng nhiều lần hoặc kết hợp với tùy chọn -f (--file), nó sẽ tìm kiếm tất cả các mẫu đã cho. Tùy chọn này có thể được sử dụng để bảo vệ một pattern bắt đầu bằng “-”. (vd : -million)
